# 프로젝트 요구사항 정의서 (PRD) 및 시스템 설계서
**프로젝트명:** MatchFit Color (인터랙티브 패션 상·하의 컬러 매칭 서비스)  
**문서 버전:** v1.0.0  
**작성 목적:** 코딩 에이전트(LLM 기반 코드 생성기/자동화 개발 툴) 구현용 명세서

---

## 1. 프로젝트 개요
* **서비스 목적:** 상의나 하의 중 한 가지 기준 색상을 선택했을 때, 패션 스타일링 규칙 및 색채학 기반으로 어울리는 반대편 의류 색상을 추천하고 실시간으로 의류 실루엣에 반영하여 배색 고민을 해결함.
* **타깃 사용자:** 매일 아침 옷 색상 조합에 어려움을 겪는 일반 사용자, 톤온톤/뉴트럴/대비 배색을 직관적으로 확인하고 싶은 패션 입문자.
* **실행 환경:** 반응형 웹 SPA (모바일 웹 및 데스크톱 브라우저 최적화).

## 3. 기능 요구사항 명세 (Functional Requirements)

### FR-01: 기준 모드 전환
* 사용자는 `상의 기준(Top-First)` 또는 `하의 기준(Bottom-First)`을 선택할 수 있다.
* 기준 모드 변경 시:
  * 팔레트에서 선택하는 색상이 해당 부위(상의/하의)에 반영된다.
  * 하단 추천 영역은 반대편 부위(하의/상의)의 추천 색상 목록으로 갱신된다.

### FR-02: 의류 실루엣 SVG 렌더링 & 연동
* 상의: 기본 티셔츠/셔츠 형태의 벡터 SVG.
* 하의: 슬랙스 팬츠 또는 A라인 스커트 형태의 벡터 SVG.
* 각 SVG의 채우기 속성(`fill`)은 애플리케이션의 State(`topColor`, `bottomColor`)와 실시간 바인딩된다.
* 음영(그림자/주름선)은 반투명 검정(#000000 10~15% 투명도) 레이어로 덮어 어떤 색상이 채워져도 입체감이 유지되도록 구현한다.

### FR-03: 하의 실루엣 형태 토글
* 라디오 버튼 또는 토글 스위치로 `바지(pants)`와 `치마(skirt)`를 전환할 수 있다.
* 선택 변경 시 하의 SVG 경로(path)가 즉시 교체된다.

### FR-04: 컬러 팔레트 및 상태 관리
* 15가지 대표 패션 컬러 스와치 제공.
* 현재 선택된 기준 색상 스와치에는 강조 테두리(Active Border/Ring) 표시.
* 추천 색상 카드 클릭 시, 반대편 의류 색상이 즉각 변경되고 활성화 상태가 표시된다.

### FR-05: 빠른 스왑 & 리셋 (부가 편의기능)
* **상·하의 색상 반전(Swap) 버튼:** 현재 상의 색과 하의 색을 서로 맞바꾸는 편의 기능.
* **랜덤 조합(Shuffle) 버튼:** 조화로운 베스트 조합 1세트를 랜덤 선택.

## 4. 프론트엔드 상태 인터페이스 (TypeScript Interface)

```typescript
export type TargetMode = 'top' | 'bottom';
export type BottomType = 'pants' | 'skirt';

export interface Recommendation {
  id: string;
  name: string;
  hex: string;
  vibe: string;
}

export interface FashionColor {
  id: string;
  name: string;
  hex: string;
  textColor: '#000000' | '#FFFFFF'; // 스와치 내부 텍스트 가독성용
  recommendations: Recommendation[];
}

export interface AppState {
  activeMode: TargetMode;
  bottomType: BottomType;
  selectedTop: FashionColor;
  selectedBottom: FashionColor | Recommendation;
}
```
