## 📌 프로젝트 소개

**MatchFit Color**는 색상 조합에 서툰 사람들을 위해 색채학 및 실제 패션 스타일링 규칙에 기반하여 완벽한 배색을 제안하고, **실시간 마네킹 피팅 시뮬레이션**, **TPO/요일별 데일리 코디**, **지역 실시간 날씨 연동 옷차림**, **국내외 출장·여행 7일 날씨 & 캡슐 옷장 패킹 플래너**, **시즌 트렌드 큐레이션**을 통합 제공하는 스마트 패션 웹 애플리케이션입니다.

## 🌟 5대 핵심 서비스 구성

MatchFit Color는 스마트폰 및 데스크톱 어디서나 최적화된 **통합 GNB 및 모바일 5탭 네비게이션 바**를 통해 5대 전문 기능 간을 자유롭게 오갈 수 있습니다.

```
┌────────────────────────────────────────────────────────────────────────┐
│  [🎨 컬러 스튜디오]  [📅 매일 코디]  [🌤️ 날씨 코디]  [✈️ 출장·여행]  [🍂 시즌 트렌드] │
└────────────────────────────────────────────────────────────────────────┘
```

### 1. 🎨 비주얼 코디 프리뷰 (컬러 매칭 스튜디오 - 메인 `index.html`)
* **3분할 LIVE FIT 스튜디오:** `마네킹 피팅 스테이지 | 컬러 팔레트 | 5대 테마 탭 세로 레일` 통합 배치로 접속 즉시 시뮬레이션 몰입.
* **유연한 상의 옵션 (1벌 단품 vs 2벌 레이어드):** 계절에 구애받지 않고 사용자가 원클릭으로 **상의 1벌(티셔츠/크루넥)** 또는 **상의 2벌(외투 + 이너 레이어드)** 구성을 자유롭게 선택.
* **하의 실루엣 옵션 (바지 vs 치마):** 슬랙스 팬츠 ↔ A라인 플리츠 스커트 실시간 전환 지원.
* **3벌 유기적 동시 배색 연동:**
  - 외투 선택 시: 이너와 바지가 둘 다 외투에 최적화된 추천 컬러로 동시 반응.
  - 바지 선택 시: 외투와 이너가 둘 다 바지에 어울리는 추천 컬러로 동시 반응.
  - 이너 선택 시: 외투와 바지가 둘 다 이너와 조화로운 추천 컬러로 동시 반응.
* **차별화된 부위별 패션 추천 공식 ([04_Layered_Fashion_Color_Formulas.md](Doc/04_Layered_Fashion_Color_Formulas.md)):**
  - **이너(Inner)**: V존을 밝혀 피부 톤을 화사하게 보정하는 소프트 뉴트럴 톤(화이트, 크림, 멜란지그레이, 스카이블루 등) 엄선.
  - **하의(Bottom)**: 하체의 무게중심과 실루엣을 단정히 잡는 앵커 톤(베이지 치노, 다크브라운, 슬랙스 블랙/차콜, 데님 등) 엄선.
  - 추천 섹션에서 `[피팅 대상: 👖 하의]`와 `[피팅 대상: 👕 이너]`를 토글하여 부위별 특화된 베스트 3가지 추천 제공.
* **다이나믹 추천 컬러 순환 미리보기 (Auto-Cycle):**
  - 기준 컬러 선택 시 엄선된 3가지 추천 세트가 마네킹에 춤추듯 순환 피팅(CSS `transition: fill 0.35s`)된 후, 가장 완성도 높은 1순위 베스트 세트에서 '딱!' 멈추며 토스트 확정.
* **정밀 벡터 SVG 레이어드 그래픽:**
  - 외투 앞섶 V존(x=96~144)을 완벽히 채우면서 소매 밑/허리선 바깥으로 이너가 삐져나오지 않는 정밀 피팅(x=88~152).
  - 외투 선택 시 이너 영역으로 빛이 번지지 않도록 바깥 둘레선만 둘러싸는 `outer-perimeter-glow`로 이너 본연의 컬러 100% 보존.
* **46종 테마별 엄선 컬러 팔레트:** 대표/표준 15종, 웜톤&얼씨 9종, 쿨톤&모던 9종, 파스텔&포인트 9종, 데님&빈티지 6종.
* **편의 기능:** 3벌 순환 스왑(Swap), 랜덤 코디(Shuffle), 코디 복사(Copy), 모바일 스티키 퀵 프리뷰 바.
* **URL 파라미터 피팅 연동:** 타 페이지에서 추천 코디 클릭 시 `?topMode=...&outer=...&inner=...&top=...&bottom=...` 파라미터를 통해 마네킹에 즉시 자동 피팅.

### 2. 📅 매일매일 코디 추천 (`daily.html`)
* **오늘 요일 감지 배너:** 월요일(당당한 출근룩)부터 일요일(여유로운 원마일룩)까지 요일별 추천 테마 및 스타일 팁 실시간 제공.
* **TPO별 상황 필터링:** 💼 출근/비즈니스, ☕ 데일리/캠퍼스, 🍷 데이트/소개팅, 🎩 격식/하객룩, 🌿 원마일웨어.
* **코디 카드 큐레이션:** 상·하의 컬러 스와치, 핵심 아이템, 3대 스타일링 포인트 및 **[마네킹에 입혀보기]** 원클릭 연동.

### 3. 🌤️ 실시간 날씨에 따른 코디 추천 (`weather.html`)
* **Open-Meteo 실시간 기상 API 연동:** 완전 무료, API 키 불필요, 브라우저 직접 통신.
* **지역 선택 및 GPS 지원:** 서울, 부산, 대구, 제주 등 국내 전국 12개 주요 도시 및 `📡 내 위치 날씨 찾기 (GPS)` 원터치 지원.
* **실시간 대시보드:** 기온(℃), 체감온도, 날씨 상태(맑음, 비, 눈, 안개 등), 습도, 풍속 및 날씨별 맞춤 스타일 조언.
* **기상청 공인 8단계 기온별 옷차림 가이드:** 28℃ 이상(한여름)부터 4℃ 이하(혹한기)까지 최적의 상의, 하의, 아우터, 신발 및 어울리는 컬러 팔레트 매칭 (현재 기온 구간 하이라이트 표시).

### 4. ✈️ 출장·여행 일주일치 날씨 & 의상 플래너 (`trip.html`)
* **국내외 18+ 주요 출장지 지원:** 국내(제주, 부산, 서울 등), 아시아(도쿄, 오사카, 타이베이, 방콕, 싱가포르 등), 미주/유럽(뉴욕, LA, 런던, 파리, 프랑크푸르트 등).
* **7일간 일별 날씨 & 기온 타임라인:** 일별 최저/최고 기온 및 비 올 확률(%) 시각화.
* **Day 1 ~ Day 7 데일리 코디 스케줄:** 장시간 이동, 핵심 미팅, 파트너사 워크, 공식 만찬, 귀국 룩 등 일정별 코디 플랜.
* **스마트 캡슐 옷장 패킹 체크리스트:** 3-3-2 공식(상의 3~4벌 + 하의 2벌 + 아우터 1~2벌) 기반의 캐리어 짐 싸기 체크박스 (로컬스토리지 자동 저장 & 실시간 패킹 진행률 % 프로그레스 바).

### 5. 🍂 올가을 패션 트렌드 컬러 제안 (`trend.html`)

## 💻 로컬 실행 방법

로컬에서 테스트하거나 개발할 때 다음 방법으로 간편하게 실행할 수 있습니다.

### 방법 1: npm 스크립트 실행 (권장)
```bash
# 로컬 개발 서버 실행 (포트 3000)
npm start
```
실행 후 브라우저에서 `http://localhost:3000` 접속.

### 방법 2: npx serve 직접 구동
```bash
npx -y serve -l 3000 .
```

### 방법 3: Python 간이 서버 구동
```bash
python -m http.server 3000
```

## 🚀 GitHub Pages 배포 및 호스팅 안내

이 프로젝트는 정적 웹(Vanilla HTML/CSS/JavaScript ES Modules)으로 빌드되어 있어 GitHub Pages, Cloudflare Pages, Vercel 등 모든 정적 호스팅 플랫폼에서 별도의 빌드 과정 없이 즉시 서비스됩니다.

### GitHub Pages 배포 (저장소 Public 상태)
1. 저장소의 `.github/workflows/deploy.yml` 워크플로우를 통해 `main` 브랜치에 Push 시 자동 배포됩니다.
2. 배포 주소: `https://tramper2.github.io/MatchColorOutfit/`

> [!NOTE]
> **저장소를 Private으로 전환할 경우:**
> * GitHub Free(무료 플랜)에서는 Private 저장소의 GitHub Pages가 지원되지 않으므로 배포가 비활성화됩니다.
> * 소스코드를 비공개로 유지하면서 무료로 사이트를 계속 호스팅하려면 **Cloudflare Pages** 또는 **Vercel**에 Private 리포지토리를 무료 연동하는 방식을 추천합니다.
